assertMessageQueueContains (assert message queue contains message)

Syntax:

assertMessageQueueContains( userOrQueue : library : msgId : msgText : msgHelp : sinceTime );

Beschreibung:

Prüft, ob sich in einer gegebenen Nachrichtenwarteschlange eine Nachricht befindet, die seit sinceTime gesendet wurde. Die gesuchte Nachricht wird anhand einer Kombination aus ID, Nachrichtentext oder Hilfetext identifiziert und muss alle angegebenen Auswahlparameter erfüllen. Nicht verwendete Auswahlparameter müssen ausgelassen werden (*omit).

userOrQueue und library geben die Nachrichtenwarteschlange an. Wird library ausgelassen, ist userOrQueue der Name eines Benutzerprofils, dessen Nachrichtenwarteschlange durchsucht wird.
Die Nachrichten-ID kann auch auf *EMPTY gesetzt werden, um zu prüfen, dass seit sinceTime keine Nachricht in die Nachrichtenwarteschlange gestellt wurde. Alle weiteren Auswahlparameter müssen für diesen Fall ausgelassen werden.
Nachrichtentext und Hilfetext können als generische Zeichenkette mit * am Anfang und/oder am Ende angegeben werden, z. B. Order*, *processed oder *Order*. Groß- und Kleinschreibung wird nicht unterschieden. Vom Hilfetext werden höchstens die ersten 4096 Zeichen verglichen.
Nachrichten, die vor sinceTime gesendet wurden, werden ignoriert. Der Wert für sinceTime sollte mit Hilfe der Funktion getFullTimeStamp() gesetzt werden.

Funktionswert:

void

Beispiel 1: 

testStartTime = getFullTimeStamp();
// Ausführen des Tests, der die gesuchte Nachricht in die Nachrichtenwarteschlange stellen soll
assertMessageQueueContains( 'QMSGQT' : 'QTEMP' : *omit : 'MSGQT - iRPGUnit' : *omit : testStartTime );

Beispiel 2: 

testStartTime = getFullTimeStamp();
// Ausführen des Tests, der keine Nachricht in die Nachrichtenwarteschlange stellen soll
assertMessageQueueContains( 'QMSGQT' : 'QTEMP' : '*EMPTY' : *omit : *omit : testStartTime );
