assertJobLogContains (assert job log contains message)

Syntax:

assertJobLogContains( msgId : sinceTime );

Beschreibung:

Prüft, ob das Jobprotokoll eine Nachricht mit der gegebenen Nachrichten-ID enthält, die seit sinceTime gesendet wurde. Nachrichten, die vor sinceTime gesendet wurden, werden ignoriert.
Der Wert von sinceTime sollte mit der Funktion getFullTimeStamp() gesetzt werden.

Funktionswert:

void

Beispiel: 

testStartTime = getFullTimeStamp();
// ausführen des Tests, von dem erwartet wird, dass er eine
// Nachricht MCH1211 dem Jobprotokoll hinzufügt
assertJobLogContains( 'MCH1211' : testStartTime );
